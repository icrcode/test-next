## Descrição

Este repositório foi criado com o objetivo de estudar e explorar as funcionalidades do framework **Next.js**, utilizando **TypeScript** para desenvolvimento e **CSS** para estilização. 

O projeto foca em conceitos fundamentais como:

- Rotas dinâmicas e estáticas
- Renderização estática (SSG) e renderização do lado do servidor (SSR)
- API Routes no Next.js
- Integração e manipulação de componentes estilizados com CSS

## Tecnologias Utilizadas

- **Next.js**: Framework React para aplicações web modernas.
- **TypeScript**: Superset do JavaScript que adiciona tipagem estática.
- **CSS**: Para estilização e design da interface.

## Estrutura do Projeto

- **`pages/`**: Contém as páginas do projeto.
- **`components/`**: Componentes reutilizáveis da aplicação.
- **`public/`**: Arquivos estáticos, como imagens e fontes.
- **`styles/`**: Arquivos CSS para estilização.

## Como Usar

### Pré-requisitos

Certifique-se de ter o [Node.js](https://nodejs.org/) instalado em sua máquina.
### Passos para Rodar o Projeto

1. Clone este repositório:
   ```bash
   git clone https://github.com/icrcode/test-next.git
   cd test-next

2. Instale as dependências do projeto:
   ```bash
    npm install
    # ou
    yarn install

3. Inicie o servidor de desenvolvimento:
   ```bash
    npm run dev
    # ou
    yarn dev

4. Acesse a aplicação no navegador:
   ```bash
    http://localhost:3000
